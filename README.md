# Sistem de Gestiune și Vizualizare - Bază de Date Studenți

## 📌 Descriere Proiect
Acest proiect reprezintă o aplicație desktop dezvoltată pentru gestionarea eficientă a unei baze de date de studenți. Aplicația combină algoritmi de optimizare a datelor cu o interfață grafică interactivă, oferind o experiență de utilizare fluidă și intuitivă.

Proiectul a fost realizat în cadrul cursului de **Programarea Calculatoarelor și Limbaje de Programare (PCLP)** la **Universitatea Tehnică „Gheorghe Asachi” din Iași**.

## 🚀 Caracteristici Principale
*   **Bază de Date Optimizată:** Implementare eficientă pentru stocarea, căutarea și sortarea datelor studenților.
*   **Interfață Grafică (GUI):** Dezvoltată utilizând **OpenGL**, oferind o reprezentare vizuală a datelor și meniuri interactive.
*   **Gestiune Completă:** Permite adăugarea, modificarea și vizualizarea înregistrărilor.
*   **Integrare Date:** Sistemul este configurat să lucreze cu fișiere de intrare specifice pentru popularea automată a bazei de date.

## 🛠️ Tehnologii Utilizate
*   **Limbaje de programare:** C / C++.
*   **Grafică:** OpenGL.
*   **Mediu de dezvoltare:** VS Code / Eclipse.
*   **Controlul versiunilor:** Git și GitHub.

## 📂 Structura Repository-ului
*   `/medii_opengl` - Conține implementarea părții grafice și a elementelor de vizualizare.
*   `/StudentLauncher` - Modulul principal de lansare și logica de business a aplicației.
*   `Manual de Utilizare.pdf` - Documentație detaliată despre utilizarea aplicației.
*   `referat_proiect_oficial.pdf` - Documentația tehnică a proiectului.
